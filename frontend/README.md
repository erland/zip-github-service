# zip-github frontend

React, TypeScript and Vite frontend for the mobile-friendly ZIP-to-GitHub flow.

## Current routes

- `/projects` — project list
- `/projects/:projectId` — project overview
- `/projects/:projectId/imports/new` — new import shell
- `/about` — product principles

The current routes use clearly marked demo data. API integration and authenticated routing are introduced in later implementation steps.

## Commands

```bash
npm ci
npm test
npm run build
```
