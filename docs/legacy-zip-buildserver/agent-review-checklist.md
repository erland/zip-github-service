# Agent Review Checklist

Use this checklist after every implemented step.

## Scope

- [ ] Exactly one step was implemented.
- [ ] No unrelated cleanup was performed.
- [ ] No future steps were implemented accidentally.

## Specification and plan alignment

- [ ] The change matches `docs/delivery-plan.md`.
- [ ] Relevant reference documents in `docs/reference/` were considered.
- [ ] Existing behavior was preserved unless the selected step required changing it.

## Tests and verification

- [ ] Tests were added or updated where appropriate.
- [ ] Existing tests were not weakened to hide failures.
- [ ] Verification commands were run, or exact local commands were documented.

## Documentation

- [ ] `docs/agent-progress.md` was updated.
- [ ] Changed files were recorded.
- [ ] Verification result was recorded.
- [ ] Known follow-ups were recorded.
